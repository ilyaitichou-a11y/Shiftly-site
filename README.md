# Shiftly website
Static site (no build step). Publish free with GitHub Pages: push to a repo, then Settings > Pages > Deploy from branch (main, / root).
Edit pages by changing build.py and running `python3 build.py`, or edit the .html files directly.
Before launch: replace [bracketed] legal placeholders, EMAIL in build.py, and have a Finnish lawyer review privacy.html and terms.html.
